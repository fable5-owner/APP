# THE COMPACT — 열한 개의 불, 한 사람의 손

세계의 지능을 쥔 열한 개 기업이 한 사람에게 상속된다. 회사를 운영하고, 재산을 쌓고, 사람을 믿고 의심하며,
선대 엘리아스 밴스의 편지가 숨긴 진실을 향해 가는 **전략·스토리 시뮬레이션 프로토타입**입니다.
모든 인물과 사건은 허구이며, 기업명은 가상 시나리오를 위한 소재로만 사용됩니다.

> 이 폴더는 저장소의 다른 프로젝트(홈피)와 독립된 정적 웹앱입니다. 개발할 때는 빌드가 필요 없고, 배포용 단일 파일만 위 스크립트로 만듭니다.

## 바로 플레이 (클릭 한 번)

- **`play.html`을 더블클릭**하면 서버 없이 브라우저에서 바로 실행됩니다. (게임 전체가 파일 하나에 들어 있습니다. 글꼴만 인터넷에서 받아 옵니다.)
- 소스를 고친 뒤에는 `node the-compact/tools/build-single.mjs`로 `play.html`을 다시 만드세요. (Node 18+, 처음 한 번 esbuild를 자동으로 받습니다.)

## 개발용 실행

```bash
# 저장소 루트에서
python3 -m http.server 8765 -d the-compact     # → http://localhost:8765
# 또는
npx vite the-compact
```

ES 모듈을 쓰므로 `file://`로 직접 열면 동작하지 않습니다. 글꼴은 Google Fonts(Cinzel, Noto Serif/Sans KR)를 불러옵니다.

## 한 판의 흐름 (프로토타입 = 12분기)

1. **프롤로그**(비주얼 노벨) → 과거 선택(감사인/엔지니어/펀드 분석가) → 첫 편지
2. 매 분기: **회의/이벤트 결정** → (선택) **🏢 회사 지렛대 조정** · **👛 배당 성향·소비** · **🕵️ 용의자 조사** → **END TURN**
3. **어닝스 데이**(실적 발표, 내 몫 정산) → 다음 분기
4. 10분기: 첩자 지목 · 9분기: 거품의 갈림길(연착륙/가속/폭락 베팅) · 12분기: 엔딩

핵심 시스템: 11개 기업 손익(매출·마진·성장·가동률·사기·규제·평판·현금), 거품 지수, 인물별 신뢰도, 숨은 첩자(매 게임 무작위),
개인 재산(급여·배당·성과보수·개인 펀드), 헌장 배당 상한(40%)과 감사 위험, 선대 편지 7통(프로토타입에서 4통).

## 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `css/style.css` | 1920×1080 스테이지(창 크기에 맞게 자동 스케일), 화면별 스타일 |
| `js/data.js` | **콘텐츠 전부**: 기업, 인물, 과거, 이벤트(대사·선택지·효과), 편지, 엔딩 |
| `js/state.js` | 게임 상태와 경제 엔진(DOM 없음). 분기 계산, 효과 적용, 엔딩 판정, 저장/불러오기 |
| `js/ui.js` | 화면 템플릿(문자열 반환) |
| `js/main.js` | 라우팅, 입력 처리, 턴 흐름 |
| `js/map.js`, `js/geo.js` | 양피지풍 헥스 세계지도 생성(시작 시 1회) |
| `js/portraits.js` | 코드로 그린 임시 초상화(SVG) |
| `play.html` | **배포용 단일 파일**(생성물). `tools/build-single.mjs`로 만듭니다 |
| `art/` | 실제 일러스트로 교체하는 방법: `art/README.md`, 프롬프트: `art/PROMPTS.md` |

## 이야기/밸런스 손보기

- 이벤트 추가·수정: `js/data.js`의 `EVENTS` (효과 키는 파일 상단 주석 참고) 와 `SCRIPT_ORDER`
- 경제 수치: `js/data.js`의 `COMPANIES`, 계산식은 `js/state.js`의 `endTurn()` / `previewCompany()`
- 거품이 터지는 조건: `endTurn()`의 `bubble` 관련 부분 (6분기 이후, 연착륙 플래그가 없을 때)

## 알려진 한계 (프로토타입)

- 12분기만 구현(정식 계획은 40분기). 편지 4/7통, 엔딩 5종.
- 초상화는 임시 벡터 일러스트. 사운드/BGM 없음.
- 기업 내부 사정과 수치는 모두 게임용 가상 모델이며 실제와 무관합니다.
